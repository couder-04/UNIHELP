================================================================
HOW TO RUN THIS AGAIN
================================================================

1. Local Postgres up, .env pointing at it, OpenRouter key in .env.
2. .venv/bin/python scripts/create_iit_mandi_demo_db.py
   (if mandi_* databases are missing)
3. bash scripts/run_iit_mandi.sh
4. Open http://127.0.0.1:8002/ask
5. Admin: mandi-admin
   Student: mandi-asha
   Faculty: mandi-faculty

To go back to IIT Patna, stop the Mandi process and start
`.venv/bin/python main.py` with the default .env (no ORG_PROFILE_PATH,
original *_DB_NAME values).


================================================================
CAVEATS
================================================================

- Isolation is by database name, not a second Postgres server.
- admin-demo / student-demo / faculty-demo live only in the Patna DBs.
- Mess seed for a new hostel will fail unless a (hostel, day) row already
  exists (the Mandi provisioner inserts Chandra and Suvalsar weeks).
- Library books are JSON feature rows, not a new SQL table.
- iit_mandi.yaml.bak is an intermediate save from update_org_profile;
  the live file is orgs/iit_mandi.yaml.

Assumptions that move the bill

Fast-path now zeros mess, bus, notices, and timetable when the phrasing is obvious. If real traffic is 70%+ those lookups, the DeepSeek LLM line drops toward $1.30/day.

Paid estimates use OpenRouter DeepSeek Flash 0731. There is still no public per-token list for LLM_MODEL=kado on awesome.kado.so; if that gateway is free, you only pay infra.

LLM_FAST_MODEL=qwen/qwen3.8-27b is not a cheaper planner. Qwen output is ~11× DeepSeek ($1.875 vs $0.162 / 1M). Keep both tiers on Flash unless you need Qwen for quality. The 800-token fast-tier cap stops planner dumps; it does not cap executor synthesis.

Cap completion tokens on executor synthesis if the 8k-token bug class returns. That single failure mode still triples a campus-typical DeepSeek day if ~8% of live traffic hits it.

Two admin prompts — campus database and new agent

Sign in as admin (admin-demo until you import your own key). The server must already be running. Fill every [BRACKET] before pasting. Send Prompt 1 first; send Prompt 2 only after Prompt 1 succeeds.

Do not put SQL in either prompt. Prompt 1 writes the org YAML and people rows, then seeds mess/bus/notice through those agents. Prompt 2 registers a JSON record service (list / search / add) — it does not CREATE TABLE.

Prompt 1 — set up the campus database

Collect this before you paste

RequiredRules
Campus display nameOfficial name students will see
TimezoneIANA, e.g. Asia/Kolkata
Enabled agentsSubset of: mess, bus, complaint, room_booking, attendance, notice, timetable. Day college: omit mess and bus
Student id regexMust compile. IIT-style: ^[0-9]{4}[A-Z]{2}[0-9]{2}$
HostelsIf mess is on: ≥1 name. Aliases optional
RoomsIf room_booking is on: map onto SAC Hall, Guest House, CLH, Auditorium (those four booking types are fixed)
BusesIf bus is on: names like Bus 01
MealsIf mess is on: usually breakfast, lunch, snacks, dinner
Complaint categoriesIf complaint is on: ≥1, e.g. academic, hostel, mess
People CSVHeader role,name,roll_number plus optional authentication_key. Roles: student / faculty / admin. ≥1 of each. Students must match the regex. Max 500 rows
Seed rowsOptional but needed to go live: one menu, one bus trip, one notice if those agents are on. Skip disabled agents

Empty catalog lists are rejected. A student roll that fails the regex aborts the whole people import. Generated authentication keys are shown once — copy them from the reply.

Prompt 2 — define a new agent

This registers a JSON-backed service (list / search / add records). It does not create a PostgreSQL table or a new Python file. A hospital or fees system with its own schema still needs a real coded agent.

Collect this before you paste

RequiredRules
Agent nameBecomes slug library, lost_and_found. Letters, numbers, underscore. Not reserved: mess, bus, complaint, room_booking, attendance, notice, timetable, setup
One-line descriptionWhat students ask this agent to do
Keywords≥1 words the planner uses to route (“library”, “book”, “isbn”)
Fields (1–20)Each: name (snake_case), type = string / number / boolean / date, required yes/no, short description
Who may use itSubset of student, faculty, admin
Seed records (optional)One sample row so search works immediately

Students can list, search, and add. There is no delete/update tool on this path.

What these prompts will not do

RequestWhat actually happens
“Run this SQL” / “create a fees table”Rejected. Setup has no SQL tool. Invalid org YAML is refused; previous file kept as .bak
“Add a hospital agent with its own schema”Not a JSON feature. That needs a real agent in the registry — engineering work
Empty catalog (no hostels, no buses)Save fails loud. A missing field must not silently disable a route
Student or faculty trying setupPlanner does not offer setup. The agent itself also refuses
Reuse a built-in name (mess, bus, …)add_feature returns an error. Reserved slugs cannot be overwritten
After Prompt 1, before students Copy generated authentication keys offline. Confirm a hostel alias resolves and one live query per enabled agent uses the new campus names, not IIT Patna leftovers.
